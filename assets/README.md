# Figure assets

The figures in this directory were rendered and cropped from the authors'
published paper while assembling this repository:

> D. Yue, X. Liu, W. Fan, J. Zhong, X. Liu, and Y. Zhang, “A Universal
> Framework for Remote Sensing Image Color Correction via Style Transfer,”
> *IEEE Transactions on Geoscience and Remote Sensing*, vol. 64, 2026.

- `pipeline.png`: Fig. 2, overall framework.
- `qualitative_dior.png`: Fig. 7, qualitative comparison on DIOR.
- `high_resolution_results.png`: Fig. 8, high-resolution comparison on SCHOOL.

The assets were rendered at 240 DPI and cropped to the figure boundaries. No
experimental result or visual content was altered.
The complete paper PDF is not redistributed in this repository; use the DOI in
the root README to access the publication.
